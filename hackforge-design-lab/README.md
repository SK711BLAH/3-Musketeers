# SHADOWPRINT

A behavioral identity and account-handoff detection prototype for the **Secure & Smart Automation** theme. The experience uses fictional, browser-only simulation data and performs no real security operations.

## Setup

```bash
cd hackforge-design-lab
npm run setup
```

## Run

```bash
npm run dev        # http://localhost:5175
```

Stop any server with `Control-C` in its terminal.

You can also run a project directly:

```bash
cd hackforge-design-lab/domino-effect
npm install
npm run dev
```

## Experience

- **Shadowprint** — explore the rider command center, Behavioral DNA, six deterministic Intelligence Lab scenarios including Ghostshift, the TrustBalance policy simulator, stateful investigations, and the rider-facing portal.

Shadowprint uses React, Vite, GSAP, Lucide React, custom CSS, and custom SVG.
